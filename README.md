# Top Title Header Bar

Top window header bar with active project path, dirty buffer indicator, and quick buttons

## Details
- **Identifier**: `matn.ext.topbar`
- **Version**: `1.0.0`
- **Category**: `editor`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Top Title Header Bar**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-topbar
```
